# 🃏 Royal Blackjack Casino

A stylish, interactive web-based **Blackjack game** built with Python and Streamlit. Play against an automated Casino Dealer or challenge a friend in 2-Player Pass & Play mode!

---

## ✨ Features

- 🎴 **Realistic Card UI**: Custom CSS card visuals with suits (♠ ♥ ♦ ♣), ranks, face card values, and hole card backs.
- 🎰 **Casino Felt Aesthetic**: Emerald green casino table styling with gold accents.
- 👥 **Two Game Modes**:
  - **Player vs Dealer**: Challenge the casino AI (Dealer hits on soft 16, stands on 17+ with hidden hole card).
  - **2-Player (Pass & Play)**: Compete head-to-head with a friend on the same screen.
- 🧠 **Dynamic Ace Logic**: Automatically calculates Aces as 11 or 1 to prevent accidental busts.
- 🏆 **Win/Loss Scoreboard**: Tracks round wins, dealer wins, and pushes/draws across sessions.
- 🎉 **Celebration Effects**: Confetti and balloons when you win!
